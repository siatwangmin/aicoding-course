# 工具使用入口

首次使用打开[环境准备](preparation.html)，开发时打开[操作手册](index.html)，其他业务可以打开[自己的作品](custom.html)。图文、步骤、求助和更新记录在线阅读，执行资料由 Trae 获取。

环境准备完成工具、GitHub、CloudBase 与必要授权并汇总；已有准备直接复用。本人处理必要登录、授权、费用或重启，助手接续剩余工作。不要求提前注册或配置模型服务。

手册中按用途调用用户级技能：ai-coding-project 初始化本地项目；ai-coding-github 发布静态网页；ai-coding-cloudbase 实现数据库、多端共享和 AI 后端；ai-coding-android 生成 APK。准备、恢复和卸载由准备目录中的 ai-coding-env 处理。各项能力按需组合。

本地开发直接按项目 AGENTS、工程指南、需求和设计进行；初始化不提前接入远端资源。每轮交接需求说明文档.md 与完整设计 HTML，用户确认需求、页面和试用结果，助手维护版本、技术实现与验证。
