# AI Coding 工具与操作手册

首次使用打开[环境准备](course/preparation.html)，开发时打开[操作手册](course/index.html)，也可以参考[自己的作品](course/custom.html)。工具包由助手获取；手册、图片与求助在线阅读。

环境准备一次完成工具、GitHub、CloudBase 和必要授权，已有有效状态直接复用。模型服务账号与 Key 不作为安装条件。

用户级提供 ai-coding-project、ai-coding-github、ai-coding-cloudbase、ai-coding-android；准备目录只保留本地 ai-coding-env。手册提示明确调用对应技能，技能也支持按自然语言目标使用。

初始化只准备本地工程并启动网页；静态网页发布、数据库与多端共享、APK 打包分别按当前需求执行。工具和镜像可跨项目复用，项目资源与授权独立绑定。

AI 只在功能需要时配置。用户在程序设置中填写服务地址、模型和 Key，秘密由受保护服务端保管。准备、接入、实际调用、发布、安装和本人试用分别验证。
