# AI Coding 实操课

课前打开[课前环境准备](course/preparation.html)，上课打开[操作手册](course/index.html)；做其他业务打开[自己的作品](course/custom.html)。手册、图文、求助与更新记录直接在课程网站阅读，不必另外下载说明书。

环境准备由 Trae 连续完成课程所需工具、云服务、GitHub 和 AI 账号及必要授权，已有结果直接复用。新环境采用 Podman CLI + 独立 Docker Compose；已有工程保留原引擎与镜像。

项目初始化时，助手读取已有准备，根据本项目当前已确认需求接入云服务、GitHub 和 AI；需求尚未明确时先建立本地工程。准备、接入、调用、发布和本人试用分别记录。

学员确认需求、Canvas 设计和实际体验，亲自处理必要登录、授权、费用与手机试用。PRD.md 和设计 HTML 是每轮交接材料；版本、配置、实现和测试由助手维护。

首次启用 AI、程序入口就绪后，本人在“设置 → AI 服务”填写 Key 和选择模型。Key 由受保护服务端保管，网页与安卓版共用配置；以后换模型无需重打 APK。

执行资料由 Trae 按当前路线取得：通用准备用 ai-coding-toolkit.zip；从零开始且已明确选案例用 aicoding-student-kit.zip；已有通用准备后只补案例 Skill。无须学员同时下载多个完整包。
