# 环境准备帮助

## 只看到 Trae 的独立聊天窗口

点右上角“IDE”进入编辑器，再打开准备文件夹。先核对完整路径；文件夹信任提示由本人判断并处理。

## 需要重启或下次继续

回到原准备文件夹，告诉 Trae：

```text
请读取已有记录，继续未完成的环境准备步骤，告诉我下一步做什么。
```

## 准备结果不对

将实际现象告诉 Trae，让助手检查并修复。反馈画面时遮住密码、Key 和私人资料。

```text
我做了【动作】，希望【结果】，实际看到【现象】。请检查并修复，告诉我怎样再试。需要我操作时，一次给一个动作。
```

## 哪些步骤需要联网

说明、截图、求助和更新记录在线阅读。技能和必要脚本由 Trae 下载、校验和安装；下载工具、准备账号及云端检查需要联网。已有兼容工具和账号可以复用。

## 如何更新资料与技能

回到原准备文件夹，告诉 Trae“请按照准备说明更新资料与技能，复用已有的兼容编程环境”。助手会检查并报告实际版本；资料下载、技能安装与 Trae 加载分别确认。

## 如何卸载环境

在 Trae 中说“调用 ai-coding-env 卸载环境，保留我的作品”。也可双击当前执行资料里的“卸载环境.cmd”。先看清单再执行，作品默认保留；测试项目、云端和手机应用另按明确范围处理。
