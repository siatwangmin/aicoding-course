# 建立作品

建立或恢复本地工程，复用课前准备；按本项目当前已确认需求接入云服务、GitHub 和 AI。

本阶段预计 3–10 分钟。

## 第 1 步：建立作品

**在哪操作**：Trae → 浏览器

**这样做**：

预计 3–10 分钟；复用约 1–5 分钟



1. 在 Trae 打开作品文件夹，发送下方提示。
2. 点击助手给出的起始网页，确认显示“工作空间已就绪”。
3. 助手根据当前已确认的项目需求，复用并接入需要的云服务、GitHub 和 AI；已有需求或授权直接沿用，需要本人操作时一次完成一个动作。

**现在复制到 Trae**：

```text
调用ai-coding-project技能创建项目工程。
```


**完成后**：

- 起始网页可以打开，知道作品保存位置；
- 助手说明本项目哪些能力需要接入、哪些已接入、哪些待本人操作；没有需求的能力保持未启用。
- 助手复制标准 app 并在容器中构建运行，默认端口 5187；占用时自动换端口并给出可点击地址。平台技能用户级可用，后续按当前需求调用。

**你来确认**：

- 网页显示“工作空间已就绪”。
