# 按网页完成当前一步

课前打开[课前环境准备](preparation.html)；上课打开[AI Coding 操作手册](index.html)。

1. 看当前步骤写的是 Gemini、Trae 还是浏览器。
2. 按“这样做”操作；有提示词就复制到指定工具发送。
3. 按“完成后”和“检查”核对结果。
4. 通过后勾选完成，点“下一步”。有问题先修复再试。

课前从“环境准备”完成工具检查、云服务、GitHub 账号和 AI 服务准备。已有作品可按进度继续；进入云端版或 AI 阶段时复用课前准备，不重复注册。作品演示账号由助手准备，打开即可使用，不另练注册和登录。

本课使用 Trae／TRAE CN。电脑上还有 TRAE Work 时，先确认打开的是 Trae；独立 Agent 窗口可点右上角“IDE”进入编辑器。文件夹信任提示由本人核对路径并判断。

已有作品时，在 Trae 打开原作品文件夹，先发送：

```text
请报告当前作品的完整路径，读取已有需求、原型、进度和工具检查记录，告诉我对应网页的哪一步。保留全部已有修改，不重新初始化、不建立空白作品。
```

已有业务页面时，不需要退回空白页面。按已有记录继续当前轮需求、设计和验证。

## 结果不对时

对当前使用的助手说：

```text
我做了【动作】，希望【结果】，实际看到【现象】。请修复后告诉我怎样再试。
```

原型问题问 Gemini，作品问题问 Trae。

## 下次继续

在 Trae 打开同一个作品文件夹，发送：

```text
请用课程助手读取这个作品的需求、设计和进度，告诉我对应网页的哪一步，以及下一步做什么。
```
