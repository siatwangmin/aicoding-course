# 分享网页：能打开与能共享内容分别验证

**这一步的目标：拿到可以分享的网页链接，并判断分享后哪些能力已经可用。** 本课 V2 默认发布到你自己的 CloudBase 静态托管；GitHub Pages 仅是另选的静态发布补充练习。作品内容共享由你自己的云服务承担，课程助手会分别处理。

这是 V2 本轮已确认需求中的发布操作。若现在改变分享范围或新增功能，先回 Gemini 更新 PRD 与 Canvas 设计，再实施。

## 第一步：让助手准备分享发布

```text
请把当前网页准备成可以分享给他人的链接。发布方式使用课程默认方案。需要我登录或授权时，告诉我点哪里和应该看到什么。完成后给我链接，并分别说明“网页能打开”和“数据能共享”是否已验证。
```

**你要做**：按默认方案在 [CloudBase 控制台](https://tcb.cloud.tencent.com/)完成本人授权；只有明确选择 GitHub Pages 补充练习时，才在 [GitHub](https://github.com/)处理对应设置。密码只在官方网站输入。

**预期结果**：助手给出发布状态和链接。账号或网站暂时无法访问时，明确记录未验证，先继续完成云端保存案例，避免停在分享网站一步。

## 第二步：检查分享范围

如果你分享的是 V1，别人可以打开页面，但不会自动看到你电脑里保存的内容。若已完成 V2，同一练习账号的不同设备应看到云端保存的练习内容。

```text
请引导我检查分享后的作品。我先要确认链接能打开，再确认使用同一练习账号时本轮约定的内容能共享。哪一项没有实测，就单独写为“尚未验证”。
```

**过关检查**：网页发布与云端保存分开报告；真正发布成功后再尝试另一个设备打开。只使用虚构练习内容，不公开私人资料。
