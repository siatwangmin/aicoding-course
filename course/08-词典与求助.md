# 遇到问题，怎样告诉助手

| 你遇到的情况 | 告诉谁 |
| --- | --- |
| 想增加功能或改变操作规则 | Gemini，先更新需求和页面设计 |
| Canvas 设计不好用或看不懂 | Gemini |
| 做出来的作品与确认设计不一样 | Trae |
| 安装、工具或账号准备遇到提示 | Trae，按它的单步指引处理 |

不确定是哪种问题，先让助手判断。你不用猜技术原因。

## 有问题时，填入实际情况再发送

```text
我做了【动作】，希望【结果】，实际看到【现象】。请检查并修复，告诉我怎样再试。需要我操作时，一次给一个动作。
```

例如：“我新增题目并保存，刷新后不见了；应该保留。请修复后让我再试。” 反馈画面时遮住密码、Key 和私人资料。

## 说明看不懂时

```text
请用日常语言告诉我现在要做什么、做完会看到什么。技术检查由你处理。
```

## 这些名称只需知道用途，不用背

| 名称 | 用途 |
| --- | --- |
| Gemini / Canvas | 讨论需求 / 试用页面设计 |
| Trae | 让助手做出作品、检查并修复 |
| PRD.md | 保存需求说明的文件 |
| know-star.html | 可以打开的页面设计文件 |
| 课程助手（Skill） | 助手的工作说明，你不用打开 |
| Docker Desktop / Podman Desktop | 二选一运行课程容器工具，由助手准备和实际检查 |
| CloudBase | 保存和共享作品数据的云服务 |
| APK | 安卓手机的安装文件 |
| Key | 使用 AI 服务的秘密钥匙，只填到指定的隐藏输入窗口 |

你确认需求和可见结果；助手检查配置、文件、调用和错误。下次继续时，打开原作品，对 Trae 说“请读取已有记录，告诉我下一步做什么”。
