# 云服务准备（课前 E-06）

打开[课前环境准备](preparation.html)，到第 5 / 8 步“课前接好云服务”，复制该页提示到 Trae。已有账号直接用，不重复注册。还没有作品也可以先准备。

**你本人做**：跟随助手打开的页面完成登录、实名和授权；查看免费资格或费用，由本人决定。密码、验证码和实名资料只在本人页面填写。

等待 Trae 告诉你准备结果；有缺项时按它的单步指引继续。

中途离开后，在原 Trae 任务说：

```text
请从已有记录继续云服务准备，只补还没完成的步骤。需要我操作时，一次告诉我一个动作。
```

准备好后回课前网页，继续 GitHub 和 AI 服务准备，最后让助手汇总结果。作品建立后，配置由助手接入；进入 V2 只复查补缺。云服务准备好不代表作品已经发布，发布与共享在 V2 再实际验证。
