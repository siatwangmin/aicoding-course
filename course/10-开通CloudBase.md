# 云服务开通：让一个助手陪你走完

在课前“环境准备”的 E-06，打开课程工作区的 Trae **本地任务**。还没有作品也可以开始。助手用 BrowserUse 打开并操作浏览器，陪你完成登录、注册和实名；随后接入腾讯云官方 CloudBase Skill，由它处理环境、密钥和配置。密码、实名和授权批准由你在页面完成，不需要理解代码或手动改文件。

## 只发这一句话

```text
请用 ai-coding-cloudbase 帮我把 CloudBase 接好。我完全不懂技术，请用 Trae BrowserUse 一步一步带我注册、登录和实名；然后读取 https://docs.cloudbase.net/skill.md，按说明接入腾讯云官方 Skill，由它处理课程环境和 Publishable Key，已有作品时定位真实配置并保留原内容；还没有作品时先保存准备结果，建立作品后由你接入。完成后告诉我，并建议最相关的下一步。
```

课程资料包会自动安装这个助手。单独使用时，[下载技能 ZIP](../ai-coding-cloudbase-skill.zip)，在 Trae“插件市场 → 技能 → 上传技能”导入；安装与调用入口见 [Trae 官方说明](https://docs.trae.cn/work_skills)。

没有作品时，助手会先保存连接信息；你不用抄写或移动文件。作品建立后由助手接入。

助手一次只让你做一个必须本人完成的动作，其余操作由它连续处理。下面这张表供你知道进度，不需要一次做完。

| 走到哪里 | 你本人做什么 | 完成后看到什么 |
| --- | --- | --- |
| 打开服务 | 助手用 BrowserUse 打开 [CloudBase 控制台](https://tcb.cloud.tencent.com/) | 登录页或环境列表 |
| 登录与实名 | 助手点击和导航；你本人填写或扫码完成账号与实名校验 | 助手读取到“已认证／认证通过” |
| 接入官方助手 | 助手按官方说明接入；你在它打开的授权页面批准 | 官方 Skill 可用，管理工具已授权并能查询环境 |
| 创建练习空间 | 助手核对当前免费资格并准备具体方案；需要确认时你核对该摘要 | 官方工具创建或复用 PostgreSQL 环境，取得真实 EnvId |
| 取得连接钥匙 | 官方 Skill 查询或生成同一环境的 Publishable Key，无需你复制 | 助手取得正确类型的 Key |
| 保存和检查 | 助手复制示例、填入两个值、实际读取目标环境并检查文件 | 助手给出 `.env` 文件链接及真实接入检查结果 |

密码、短信验证码和实名资料只在腾讯云页面填写，不发给助手。连接值由官方工具获取；不需要你提供服务端 API Key 或腾讯云 SecretId／SecretKey。BrowserUse 无法使用时，助手才给单步官方入口，不假装已操作；BrowserUse 的启用入口见 [官方说明](https://docs.trae.cn/work_browser-use)。

已有腾讯云账号、希望直接接入时，也可以只发送：

```text
帮我把 CloudBase 接好，按下面做：
1. 打开https://docs.cloudbase.net/skill.md ，按说明完成接入。
2. 接入完成后告诉我，并建议最相关的下一步。
```

陪练会复用已完成步骤，缺少注册或实名才补上。官方 Skill 的安装、授权、环境和连接检查由它处理，不需要你粘贴技术配置。首次会话若 MCP 尚未加载，助手可以按官方说明用官方 CLI 完成，并说明 MCP 仍待刷新，不能把安装成功当作实际连接成功。

免费资格与费用以你当前账号页面为准。[官方定价](https://www.cloudbase.net/pricing)目前将免费体验与收费方案分开列出，不要把“按量付费”理解成永远免费。出现应付金额、充值或超额收费要求时，让助手先解释再决定。页面和课程截图不同也以当前页面为准；找不到按钮时，把按钮文字或不含个人信息的截图交给助手。

中途离开后，在同一个作品任务说：“请继续上次 CloudBase 开通，从没完成的那一步开始。” 已有账号、空间和连接值会复用，不需要重建。

**过关检查**：本人账号已实名，官方助手和管理工具已实际授权，可读取本人练习空间；连接信息已由助手保存并检查。没有作品时先保存在工作区，已有作品时接入实际配置。准备好不代表作品已经上线或完成数据共享。

## 课前准备完成后

继续建立作品、梳理需求和试用原型。已经完成 V1、正在做 V2 时，才发送下面的话：

```text
云服务准备已完成。请继续按本轮已确认的需求和 Canvas 设计接入云端保存，使用课程演示账号完成实际保存验证，告诉我如何亲自检查跨设备同步。
```

课前按网页继续准备 GitHub，再 [建立作品](02-工程模板.md)；已有作品进入 V2 时只检查和复用准备结果。接入所需工具、授权和业务配置由助手继续处理；不把配置文件写好当作联网成功。腾讯云管理账号由本人使用，作品演示账号由助手准备并自动登录，不用另做账号练习。
