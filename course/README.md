# 学员入口

课前打开[课前环境准备](preparation.html)，按 7 步完成工具与账号准备。上课打开[AI Coding 操作手册](index.html)，从建立新作品开始。两个页面顶部可互相切换。

| 顺序 | 做什么 |
| --- | --- |
| 环境准备 | 安装打开 Trae → 助手下载资料和安装包 → 准备工具 → 接好云服务 → 准备 GitHub → 准备 AI 服务 |
| 建立作品 | 选择空文件夹 → 建立新作品 → 打开空白页面 |
| 需求与原型 | Gemini 写 PRD → Canvas 试页面 → 保存两份文件 |
| V1 本地网页 | Trae 实现 → 保存、刷新、复习和打印检查 |
| V2 云端网页 | 更新设计 → 检查课前云服务 → 发布和共享检查 |
| V3 安卓使用 | 更新手机设计 → 安装到手机 → 操作和同步检查 |
| V4 AI 辅助 | 每次加一项功能 → 更新设计 → 开发和试用 |

课程中的作品逐步迭代，每次按当前步骤继续。按“这样做”操作，注意提示词写的是现在发送、遇到问题还是试用后反馈。只确认需求、页面和实际体验；有勾选框时记录自己的操作。

**资料分工**：你看网页；Trae 使用 `knowstar-course` 课程助手。助手在准备阶段安装，不用你打开技能文件。

每轮只交需求文件 `PRD.md` 和页面设计文件 `know-star.html`，放入 Trae 打开的文件夹；版本和备份由助手检查。增加功能先回 Gemini 更新两份材料，再交 Trae。工具可复用，每个新作品单独建文件夹。
