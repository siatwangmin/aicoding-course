# 学员入口

双击打开 [index.html](index.html)，按当前一步操作。

| 顺序 | 做什么 |
| --- | --- |
| 环境准备 | 课前解压资料 → 打开 Trae → 准备工具 → 接好云服务 → 准备 GitHub → 准备 AI 服务 |
| 建立作品 | 首次新建选保存位置；已有作品打开原目录并续用 |
| 需求与原型 | Gemini 写 PRD → Canvas 试页面 → 保存两份文件 |
| V1 本地网页 | Trae 实现 → 保存、刷新、复习和打印检查 |
| V2 云端网页 | 更新设计 → 检查课前云服务 → 发布和共享检查 |
| V3 安卓使用 | 更新手机设计 → 安装到手机 → 操作和同步检查 |
| V4 AI 辅助 | 每次加一项功能 → 更新设计 → 开发和试用 |

工具和作品已实际检查通过时，从当前未完成步骤继续；已有作品先让 Trae 读取进度。每步按“这样做、复制发送、完成后、检查”操作；通过后再继续。

**资料分工**：你看网页；Trae 使用 `knowstar-course` 课程助手。助手在准备阶段安装，不用你打开技能文件。

每轮只交 `PRD.md` 和 `know-star.html`，按 Trae 核对的真实路径交接；旧工程可沿用原文件名与位置。增加功能先回 Gemini 更新两份材料，再交 Trae。工具可复用，每个新作品单独建文件夹。
