# 学员入口

课前打开[课前环境准备](preparation.html)，上课打开[操作手册](index.html)；其他业务使用[自己的作品](custom.html)。图文、步骤、求助和历史直接在线阅读，执行资料由 Trae 获取。

环境准备：工具 → 云服务 → GitHub → AI 账号 → 汇总。已有准备复用；本人只处理必要登录、授权、费用或重启，完成后由助手继续。

项目初始化：发现已有准备，按当前已确认需求接入所需云服务、GitHub 和 AI。没有明确需求时先建立本地工程。

课堂路线：建立作品 → 需求与 Canvas 原型 → V1 本地网页 → V2 静态展示与云端共享 → V3 安卓 → V4 逐项 AI 辅助。

每轮交接需求说明文档.md 与已确认的完整设计 HTML。学员判断需求、页面和试用结果；助手维护版本、技术实现和验证。已有设计与旧工程保留。
