# 需求与原型

在 Gemini 讨论需求，在 Canvas 试页面，保存两份设计文件。

打开[操作网页](index.html)，按当前一步做。

## 第 1 步：打开 Gemini，讨论错题本需求

**在哪操作**：Gemini

**这样做**：

1. 用电脑浏览器打开 gemini.google.com，登录自己的账号，新建对话。
2. 复制下方提示，粘贴到聊天框并发送。
3. 根据 Gemini 的问题，用自己的话逐一回答；拿不准时请它给例子。

**复制发送**：

```text
我想做一个叫“知错星”的学生错题本。学生能记录题目、图片或手绘图、学科、年级和错因，复习后逐步掌握。把错题做成可以翻面的怪兽卡。这个教学案例已确定：新题为 LV1，学生复习后自己判断并点击升级，LV1 → LV2 → LV3；达到 LV3 即完全收服，卡片仍保留在怪兽图鉴，可以继续查阅，已收服统计增加。第一版只向上升级，未掌握时保持当前等级；不增加第四级、额外封印步骤、降级或自动判题。周末 A4 练习只选 LV1 和 LV2。掌握不删除卡片，误录删除是另一项操作。
第一版先在本机保存，以后再做云端、安卓和 AI。请先帮我分析使用场景和第一版范围，每次只问一个尚未确认的功能问题；整理为我能读懂的需求说明 PRD.md。已有 PRD 和 Canvas 原型时沿用已确认内容，先不要写程序。
```


[打开 Gemini](https://gemini.google.com/)


**完成后**：

- 得到第一版需求草稿，包含使用者、录题、复习、掌握与周末练习。

**检查**：

- 我能用自己的话说出：谁用、先解决什么问题。

<details><summary>遇到问题再看</summary>

课堂先用虚构题目。以已确认 Canvas 为准：LV3 已收服卡仍在图鉴，周末练习不选它；不能把掌握理解为从图鉴删除。Gemini 的建议可能超出本轮范围：出现额外升级、降级、新归档页或五栏导航时，先请它按已确认原型修正，再继续。

</details>

步骤编号：D-01

## 第 2 步：读需求，确认怎样才算完成

**在哪操作**：Gemini

**这样做**：

1. 读 Gemini 给出的草稿；检查题目怎样录入、LV1 → LV2 → LV3 且达到 LV3 即完全收服、卡片仍能在图鉴查阅。
2. 确认 V1 不降级、不增加第四级或额外封印，周末只选 LV1 和 LV2，保存失败时输入还在。
3. 有不同想法就直接说明；确认后发送下方提示。

**复制发送**：

```text
请按刚才确认的规则整理最终第一版 PRD.md。每个功能写清“学生做什么、看到什么、我怎样试用才算完成”。本案例 LV1 → LV2 → LV3，达到 LV3 即完全收服，卡片仍留在图鉴、已收服统计增加；V1 只向上升级，不增加第四级、额外封印步骤或降级。掌握与删除误录题是不同操作，周末练习只选 LV1 和 LV2，写清保存失败时保留输入。未来的云端、安卓和 AI 只列为后续计划。已有 Canvas 时沿用其页面和交互，未经我确认不增加功能。请把尚未确定的规则指出让我决定。
```


[打开 Gemini](https://gemini.google.com/)


**完成后**：

- 一份范围明确、能读懂、有具体完成标准的 PRD。

**检查**：

- 升级、完全收服后保留、误录删除和周末选题的规则都已明确。

步骤编号：D-02

## 第 3 步：选择 Canvas，生成可点击原型

**在哪操作**：Gemini Canvas

**这样做**：

1. 在原 Gemini 对话，点输入框附近的“＋／添加文件／上传和工具”，找到 Canvas；若工具收在“更多工具”里就展开。
2. 已有确认原型时，先在“上传和工具 → 文件”附上原 HTML，等上传完成，再发送“已有设计继续”提示；首次设计才发送“首次生成”。
3. 等 Canvas 的网页预览出现，再亲自试用。

**已有设计继续：复制发送**：

```text
这次继续已有作品。附件 HTML 是已确认的视觉和交互依据，请先检查 PRD 与它是否一致，指出差异，以已确认原型为准。请在 Canvas 打开它的可点击网页预览，并给出可复制为一个完整 HTML 文件的版本。保留布局、文案、怪兽图形、学科胶囊、错因胶囊、立体翻面、LV1-LV3、暖奶油底色、粗边框阴影、画笔／橡皮／清空、庆祝彩纸与声音、A4 周末试炼。保持单页怪兽卡、周末试炼和添加弹窗，不重新设计、不增加五栏导航；未经我确认不增加功能。用虚构题目，先不连接云服务或 AI。
```


**首次生成：复制发送**：

```text
请根据我们已确认的 PRD，在 Canvas 做“知错星”的可点击网页原型，输出可复制为一个完整 HTML 文件的版本。
首页是一页怪兽卡，能按学科筛选和立体翻面；录题使用弹出窗口，支持选图、手绘的笔／橡皮／清空，以及错因标签；LV1 → LV2 → LV3，达到 LV3 即完全收服，卡片仍留在图鉴且统计增加，V1 只向上升级；周末 A4 练习只选 LV1 和 LV2。外观用暖奶油底色、粗边框、清晰阴影和醒目的学科标签，掌握时有庆祝动画、彩纸和声音。保持单页，不增加五个底部栏目。未经我确认不增加功能。
用虚构题演示，标明模拟数据，先不连接真实云服务或 AI。
```


[打开 Gemini](https://gemini.google.com/)


**完成后**：

- Canvas 显示可以点击的错题本页面。

**检查**：

- 能看到卡片、添加入口和周末练习入口。

<details><summary>遇到问题再看</summary>

菜单显示“登录即可体验工具”时，先由本人登录再继续；未登录页面不能用 Canvas。登录后仍找不到时，展开页面底部“遇到问题”并查看 Google 官方说明。入口位置以当前版本为准。 预览始终空白时按下一步的排查指引下载完整 HTML 试用，并单独记录 Canvas 预览未验证。

</details>

步骤编号：D-03

## 第 4 步：亲自点击设计，让 Gemini 修改

**在哪操作**：Gemini Canvas

**这样做**：

1. 在 Canvas 切到“预览”，确认出现怪兽卡，再添加一道虚构错题，试一笔手绘，保存后找卡片并翻面。
2. 按已确认规则试等级变化，再查看周末练习和打印预览。
3. 保存后刷新页面，核对题目、手绘、等级和已完全收服统计；不能只检查卡片还在。
4. 有偏差就填下方反馈；修改后按相同动作再试，确认外观和操作。

**复制发送**：

```text
我在【页面】做了【动作】，希望【结果】，实际看到【现象】。请修正这个设计并告诉我复试动作；其他已确认内容保持。若规则因此改变，请同时更新 PRD。
```


[打开 Gemini](https://gemini.google.com/)


**完成后**：

- 你认可的设计，正常操作、没有题目和失败提示可以理解。

**检查**：

- 录题、翻卡、掌握与周末练习都按确认规则演示。
- 刷新后题目、手绘、等级与统计一致。

<details><summary>遇到问题再看</summary>

原型保存和同步可以是演示，正式开发后还要检查真实能力。预览空白时先切“代码”确认完整 HTML，再切回“预览”并试全屏；仍为空白，向 Gemini 反馈并下载 HTML 在浏览器复试。下载文件能运行与 Canvas 预览能运行分别记录，不把生成成功当作试用通过。打印没有出现预览窗口时先返回图鉴检查页面能否操作；可用普通浏览器打开下载的 HTML 再试，未看到 A4 预览就保留未验证。

</details>

步骤编号：D-04

## 第 5 步：把 PRD 和原型保存为文件

**在哪操作**：Gemini → 本课程网页

**这样做**：

1. Canvas 原型有“下载”按钮时直接下载 HTML；在下载列表找到文件，可能叫 code_artifact.html，确认内容后重命名为 know-star.html。
2. 需求文档若没有 Markdown 下载入口，使用下面提示取得完整 PRD 原文；原型没有下载按钮时取得完整 HTML。
3. 点本页“保存设计文件”，把 PRD 原文粘到需求框，把完整 HTML 粘到原型框；分别下载所需文件，已有完整 HTML 不必重复粘贴。
4. 用浏览器打开下载的 HTML，按录题、翻卡、升级和周末练习动作复试，再交给 Trae。

**复制发送**：

```text
需求和设计已经确认。请在聊天中给出 PRD.md 的完整 Markdown 原文，以及已确认网页的完整单个 HTML 代码，各自方便复制。不要改变设计，不要只给链接或片段。
```


[打开 Gemini](https://gemini.google.com/)


**完成后**：

- 电脑上得到 PRD.md 和 know-star.html 两个文件。

**检查**：

- HTML 文件打开后仍能看到并试用确认的原型。

<details><summary>遇到问题再看</summary>

本页保存工具只把粘贴内容写成文件，不上传、不生成设计。不要用浏览器“保存 Gemini 网页”。下载文件名不等于内容已确认；只给链接、片段或空白页面均不能交接。

</details>

步骤编号：D-05

## 第 6 步：在 Trae 打开作品，放入两份文件

**在哪操作**：Trae → Windows 文件夹

**这样做**：

1. 在 Trae 打开已经准备好的作品文件夹，使用本地任务；不是解压后的课程资料文件夹。先请它报告完整路径，确认是原作品，保留已有修改。
2. 发送下面提示，等 Trae 给出实际设计目录并打开它。
3. 已有确认的两份材料时沿用原路径；新下载文件先保留旧版，再从下载列表放入 Trae 指出的目录，不覆盖尚未确认的设计。
4. 回 Trae 说“两个文件已放好，请检查”，等它读取并报告结果。

**复制发送**：

```text
请使用知错星课程助手（knowstar-course）。这是知错星教学案例，继续当前作品，保留全部已有修改，不重新初始化。先报告课程助手是否实际加载、作品完整路径及现有需求和 Canvas HTML 路径；旧工程的根目录设计文件继续沿用，不为匹配 app/docs/design 另建空白工程。已有材料先读取核对，只有缺少本轮材料时才给我真实保存目录并指导放入 PRD.md 和 know-star.html。核对内容完整、一致，把真实路径和当前未验证项记入现有进度记录；先完成资料交接，暂不开发。
```


**完成后**：

- Trae 报告实际读取的两份文件路径，并复述你确认的第一版。

**检查**：

- 文件在自己的作品里，Trae 已读到正确版本。

<details><summary>遇到问题再看</summary>

新工程通常在“作品文件夹\app\docs\design”；旧工程可能在 docs/design、design 或作品根目录。沿用 Trae 实际读到的原文件路径，不迁移或重初始化。若课程助手未加载，回到准备工具步骤修复安装，再新建对话检查；只读工程内 SKILL.md 不等于技能已加载。

</details>

步骤编号：D-06

## 过关检查

能讲清录题、复习、完全收服和误录删除的规则；PRD 与已确认 Canvas 一致，并交到自己的作品。

Canvas 入口与复制操作以 [Google 官方说明](https://support.google.com/gemini/answer/16047321?hl=zh-Hans&co=GENIE.Platform%3DDesktop)及当前界面为准；分享链接不代替本地设计文件。
