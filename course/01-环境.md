# 环境准备

课前准备好工具、云服务、GitHub 和 AI 服务，课堂上直接开始作品。

打开[操作网页](preparation.html)，按当前一步做。

## 第 1 步：安装并打开 Trae

**在哪操作**：浏览器 → Trae

**这样做**：

1. 下载 Trae 安装软件包。链接：https://www.trae.cn/（推荐在Huawei-Guest 网络操作）
2. 安装 Trae 软件。如果C盘空间不足，选择“自定义安装”在非系统盘安装Trae（如下第2个图）。
3. 点右上角的“Agent”，进入工作台模式（有可能每次启动都需要点一下）。
4. 登录 Trae（推荐在 Huawei-Guest 网络登录）。
5. 选择“亮色”皮肤，告别黑暗色。
6. 电脑Wi-Fi切回到 wlanaccessv2.0 网络，设置xGate代理在国内，设置 Trae 的网络代理为国内。退出并重新打开Trae软件。
7. 认识 3 个与 Trae 交互的选项：①中输入文字/图片，和 AI 对话；②选择合适的模型，需考虑是否有图片理解能力；③选择本地的工作文件夹。
8. 建议在 D 盘根目录下创建本课程的 AI-Practice 目录，在 Trae 选择本地工作文件夹 AI-Practice。

**常见问题和操作**：

**潘少《通用AI动手》课要花钱，这次的Trae是否要充值？**

新用户首次注册赠送了4500积分，不够之后再充值。

**遇到模型不响应/输出怎么办？**

大概率是网络环境的问题，尝试重启Trae，检查接入的网络和代理。

**运行审批是否有风险？**

Trae在项目的文件空间里工作时，基本上直接点“运行”允许即可。有些任务有多次运行，容易忽略导致等待时间过长，需要多关注Trae的运行授权请求（有声音提醒）。

**为什么Trae让我接管浏览器？**

Trae内置了浏览器会进行一些自动化网页操作，但是需要登录/密码等场景时，需要人工接管操作，输完密码后在对话框告诉Trae已完成，让它继续操作。

**选择什么模型好？**

默认建议采用GLM-5.2（较快），需要识别图片的时候建议采用GLM-5.3-FlashX。

## 第 2 步：让 Trae 准备工具

**在哪操作**：Trae

**这样做**：

先在准备网页选择 **Docker Desktop** 或 **Podman Desktop**；已有哪一个就选哪一个。网页会记住选择，并将它带入下方提示。只需准备其中一种。

1. 在本页选择 Docker Desktop 或 Podman Desktop；已有哪一个就选哪一个，不用同时安装两个。
2. 在 Trae 点“打开文件夹”，选择一个用于课程练习的文件夹；没有就新建一个。出现信任提示时，由本人核对并决定。
3. 在聊天框发送下方提示；需要选择模式时，选 Agent（智能体）。
4. 按助手提示处理安装、条款或重启。重启后回到同一任务说“请继续准备工具”；等它告诉你结果。

**现在复制到 Trae（选择 Docker Desktop 时）**：

```text
我选择使用 Docker Desktop。请按这份课程准备说明准备好工具：https://siatwangmin.github.io/aicoding-course/setup-guide.md。下载、解压和检查由你完成，已有内容直接用。需要我操作时，一次告诉我一个动作。
```


**现在复制到 Trae（选择 Podman Desktop 时）**：

```text
我选择使用 Podman Desktop。请按这份课程准备说明准备好工具：https://siatwangmin.github.io/aicoding-course/setup-guide.md。下载、解压和检查由你完成，已有内容直接用。需要我操作时，一次告诉我一个动作。
```


**完成后**：

- 助手告诉你工具是否准备好；未完成时给出下一步动作。

<details><summary>遇到问题再看</summary>

选择会保存在当前浏览器，并写进复制给 Trae 的提示。安装、machine、Compose、配置和检查由助手完成；你只处理本人条款、授权或重启。准备完成后可在所选 Desktop 的容器列表查看运行结果。

</details>

## 第 3 步：课前接好云服务

**在哪操作**：Trae 与它打开的授权页面

**这样做**：

1. 在当前 Trae 任务发送下方提示。
2. 跟随助手打开的页面，本人完成登录或注册、实名和授权；已有账号直接用。
3. 查看助手说明的免费资格或费用，由本人决定；等它确认准备结果。

**现在复制到 Trae**：

```text
请用课程的云服务陪练带我准备腾讯云 CloudBase。已有账号和准备结果直接用；需要我登录、实名、授权或决定费用时，一次告诉我一个动作。配置和连接检查由你完成，最后告诉我是否准备好。
```


**完成后**：

- 助手确认云服务已准备好；未通过时说明当前缺项。

<details><summary>遇到问题再看</summary>

密码、验证码和实名信息只在本人页面填写。此时不用创建作品或发布网页。

</details>

## 第 4 步：课前准备 GitHub 账号

**在哪操作**：Trae 与它打开的 GitHub 页面

**这样做**：

1. 在当前 Trae 任务发送下方提示；已有 GitHub 账号就直接用。
2. 按助手打开的页面完成本人登录或注册、邮箱验证。
3. 等助手确认账号准备好，再继续下一步。

**现在复制到 Trae**：

```text
请用课程的 GitHub 陪练带我准备免费账号。已有账号直接用；需要我操作时，一次告诉我一个动作。登录和邮箱状态由你检查，最后告诉我是否准备好。
```


**完成后**：

- 助手确认 GitHub 账号可以使用。

<details><summary>遇到问题再看</summary>

密码、验证码和条款由本人在官网处理，不发到聊天里。此时不用创建仓库或设置推送工具。

</details>

## 第 5 步：课前准备 AI 服务

**在哪操作**：Trae 与它打开的硅基流动页面

**这样做**：

1. 在当前 Trae 任务发送下方提示，已有硅基流动账号直接用。
2. 跟随页面登录，查看额度与费用，由本人决定是否继续。
3. 按助手指引创建或复用 Key（AI 服务的调用钥匙），只粘贴到它打开的隐藏输入窗口。等助手检查结果。

**现在复制到 Trae**：

```text
请用课程的硅基流动陪练带我准备 AI 服务。已有账号和 Key 直接用；先让我看清额度和费用，再带我安全保存 Key。地址配置和实际调用检查由你完成，最后告诉我是否准备好。
```


**完成后**：

- 助手确认 AI 服务可用，或说明尚缺哪一项。

<details><summary>遇到问题再看</summary>

Key 不发到聊天里。登录、条款和付费决定由本人处理；调用地址、模型和技术配置交给助手。

</details>

## 第 6 步：最后确认课前准备结果

**在哪操作**：Trae → 检查报告

**这样做**：

1. 发送下方提示，让 Trae 汇总前面各项准备结果。
2. 若助手说“还没完成”，只处理它指出的当前缺项。
3. 助手确认课前准备完成后，点“进入 AI Coding 操作手册”。

**现在复制到 Trae**：

```text
请汇总前面工具、云服务、GitHub 和 AI 服务的准备结果，必要时实际复查。缺项请继续处理；需要我操作时一次告诉我一个动作。最后用一句话说明课前是否已准备好，未通过的不要写成完成。现在先不创建作品。
```


**完成后**：

- 助手确认四项课前准备完成，可以开始课堂操作。

<details><summary>遇到问题再看</summary>

你不用阅读日志或逐项检查配置；看助手的明确结论即可。此时还没有错题本页面是正常的。

</details>
