# 环境准备

课前准备好工具、云服务和 GitHub 账号，课堂上直接开始作品。

打开[操作网页](index.html)，按当前一步做。

## 第 1 步：解压课程资料

**在哪操作**：Windows 文件夹

**这样做**：

1. 找到收到的 knowstar-student-kit.zip，右键选择“全部解压缩”。
2. 打开解压后的文件夹，确认能看到 setup-guide.md 和几个名称带 skill 的 ZIP。
3. 双击其中的 index.html，以后按这个网页继续。

**完成后**：

- 能打开这份操作网页，课程资料已经解压。

**检查**：

- setup-guide.md 和 index.html 在同一个资料文件夹里。

<details><summary>遇到问题再看</summary>

不要在 ZIP 的预览窗口里操作，先解压。

</details>

步骤编号：E-01

## 第 2 步：安装并打开 Trae

**在哪操作**：浏览器 → Trae

**这样做**：

1. 点击下方“下载 Trae”，选择 Windows 版；已安装则直接打开。
2. 双击下载的安装程序，按提示安装并登录自己的账号。
3. 确认打开的是 Trae／TRAE CN。电脑同时安装 TRAE Work 时，本课使用 Trae。
4. 如果看到独立 Agent 聊天窗口，点右上角“IDE”进入编辑器，再找到“打开文件夹”入口。

[下载 Trae](https://www.trae.cn/)


**完成后**：

- Trae 已打开并登录。

**检查**：

- 能看到“打开文件夹”入口。

<details><summary>遇到问题再看</summary>

出现“是否信任此文件夹中的文件作者”时，先核对提示中的完整路径是否是自己选的课程资料或作品；由本人判断并处理。看到其他目录就先切回正确目录，不要为继续操作信任所有上级目录。公司电脑不允许安装时请联系 IT 支持人员。

</details>

步骤编号：E-02

## 第 3 步：放好两个安装包

**在哪操作**：浏览器 → Windows 文件夹

**这样做**：

1. 点击下方一个下载入口，下载 wsl.3.0.1.0.x64.msi 和 Docker Desktop Installer.exe；已有文件则直接使用。
2. 回到课程资料文件夹的上一层，右键新建文件夹，命名为 release。
3. 把两个安装包放进 release，保持文件名不变。先不用运行。

[公司内下载](https://clouddrive.huawei.com/p/2c5dce71d71908a8c0c64574ee5ba886)


[公司外下载（提取码 egiy）](https://pan.baidu.com/s/1so3HddPOXQVl790421DczQ?pwd=egiy)


**完成后**：

- release 文件夹内有两个安装包。

**检查**：

- release 与解压后的资料文件夹并列，两个文件都已下载完成。

<details><summary>遇到问题再看</summary>

Docker 是运行课程工具箱的程序，WSL 是它需要的系统组件。下载入口不通时，下一步让 Trae 从官方地址下载。首次取得工具箱需要联网，后续网页与安卓编译使用已准备的离线依赖。

</details>

步骤编号：E-03

## 第 4 步：让 Trae 准备工具

**在哪操作**：Trae

**这样做**：

1. 在 Trae 选择“打开文件夹”，打开刚才解压的课程资料文件夹，并核对当前文件夹名称。若出现文件夹信任提示，由本人核对完整路径并处理。
2. 在当前文件夹的 AI 聊天框粘贴下方提示并发送；若需选择模式，选 Agent（智能体）。
3. 按助手提示处理“是否允许更改”窗口；Docker 条款由本人阅读并决定是否接受。需要重启时先保存工作，重启后回到同一任务说“请继续准备工具”。

**复制发送**：

```text
我要开始 AI Coding 课程。请从当前目录读取 setup-guide.md，安装资料包里的课程助手，连续准备并验证开发工具。使用已经下载的安装包。需要我操作时，只告诉我在哪个窗口做什么；完成后打开检查报告。现在先不创建作品。
```


**完成后**：

- Trae 安装课程助手、准备工具箱，并打开检查报告。

**检查**：

- Trae 已给出检查报告的打开入口。

<details><summary>遇到问题再看</summary>

安装受限时，按助手给出的官方下载链接自行安装，再回到同一任务继续。找不到窗口时描述实际画面，不要猜测已经完成。 若助手只安装了通用技能，却说找不到知错星课程助手，请让它重新读取 setup-guide.md 和 case-profile.json，修复案例技能安装；安装后新建一个作品对话核对实际加载，不能仅凭文件存在判定启用。

</details>

步骤编号：E-04

## 第 5 步：检查工具是否准备好

**在哪操作**：Trae → 检查报告

**这样做**：

1. 打开 Trae 提供的 environment-checklist.md，查看结论是否为“已完成”。
2. 仍是“未完成”或没有报告时，复制下方提示，让 Trae 继续处理。
3. 工具通过后，继续下一步，提前接好课程云服务。

**复制发送**：

```text
请读取当前目录的环境检查记录。必要项未通过就继续处理并实际验证；完成后打开 environment-checklist.md，用一句话告诉我工具是否准备好。现在先不创建作品。
```


**完成后**：

- 检查报告显示工具准备完成，可以继续课前云服务准备。

**检查**：

- 报告中没有必要项标为“未检查”或“未通过”。

<details><summary>遇到问题再看</summary>

已有工具通过检查就复用。确实需要管理员或 IT 处理时，按助手说明处理后继续。此时还没有错题本页面是正常的。

</details>

步骤编号：E-05

## 第 6 步：课前接好云服务

**在哪操作**：Trae 与它打开的授权页面

**这样做**：

1. 工具检查通过后，在当前 Trae 本地任务发送下方提示。
2. 跟随助手打开的页面，本人完成注册或登录、实名和授权。已有账号直接复用。
3. 核对助手给出的实际免费资格或费用，再按提示完成；准备好后继续下一步准备 GitHub。

**复制发送**：

```text
请用课程的云服务陪练帮我把 CloudBase 接好，按官方说明完成接入。用浏览器一步一步带我完成需要本人处理的登录、实名和授权；免费资格与费用先让我看清。配置和实际连接检查由你完成，最后告诉我结果与下一步。
```


**完成后**：

- 账号与练习空间已准备好，连接信息已由助手保存在当前工作区。

**检查**：

- 助手实际检查过管理授权和练习空间；已有作品已填配置，没有作品时已保存准备结果。

<details><summary>遇到问题再看</summary>

提前在课前完成；实名审核或授权未完成时按助手提示处理。先不创建作品、业务数据或发布网页。腾讯云账号与以后登录作品的练习账号分别使用，密码只在指定页面填写。

</details>

步骤编号：E-06

## 第 7 步：课前准备 GitHub 账号

**在哪操作**：Trae 与它打开的 GitHub 页面

**这样做**：

1. 在当前 Trae 任务发送下方提示。已有自己的 GitHub 账号就告诉助手，直接复用。
2. 按助手打开的页面，本人填写注册或登录信息，并完成邮箱验证。
3. 助手确认账号已准备好后，继续建立作品。

**复制发送**：

```text
请用课程的 GitHub 注册陪练，一步一步带我准备好 GitHub 免费账号。已有账号就直接用；需要我操作时，只告诉我在哪个页面做什么。完成后检查邮箱已验证，告诉我结果和下一步。
```


**完成后**：

- GitHub 账号可以登录，邮箱已验证，助手已保存准备记录。

**检查**：

- 助手实际确认过登录和邮箱验证状态；没有重复注册已有账号。

<details><summary>遇到问题再看</summary>

课前完成；密码、验证码和条款由本人在官网处理，不发给助手。此时不用创建仓库或配置推送工具。网页暂时无法访问时按助手提示处理并保留进度，不把等待当作准备完成。

</details>

步骤编号：E-07

## 过关检查

Trae 可使用课程助手；工具检查通过，课前云服务和 GitHub 账号均已准备并有实际检查记录。
