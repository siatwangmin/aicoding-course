# 环境准备

课前准备好工具、云服务、GitHub 和 AI 服务，课堂上直接开始作品。

打开[操作网页](preparation.html)，按当前一步做。

## 第 1 步：解压课程资料

**在哪操作**：Windows 文件夹

**这样做**：

1. 找到 aicoding-student-kit.zip，右键选择“全部解压缩”。
2. 打开解压后的文件夹，双击 preparation.html，进入课前环境准备。

**完成后**：

- 能打开课前环境准备网页，课程资料已经解压。

**你来确认**：

- 能打开本页；操作的是解压后的文件夹，而不是 ZIP 预览窗口。

<details><summary>遇到问题再看</summary>

不要在 ZIP 的预览窗口里操作，先解压。

</details>

步骤编号：E-01

## 第 2 步：安装并打开 Trae

**在哪操作**：浏览器 → Trae

**这样做**：

1. 点击“下载 Trae”，安装 Windows 版；已经安装就直接打开。
2. 按页面提示登录自己的账号。本课使用 Trae／TRAE CN，不使用 TRAE Work。
3. 如果只看到独立聊天窗口，点右上角“IDE”，进入带“打开文件夹”入口的主窗口。

[下载 Trae](https://www.trae.cn/)


**完成后**：

- Trae 已打开并登录。

**你来确认**：

- Trae 已打开，能找到“打开文件夹”。

<details><summary>遇到问题再看</summary>

出现“是否信任此文件夹中的文件作者”时，先核对提示中的完整路径是否是自己选的课程资料或作品；由本人判断并处理。看到其他目录就先切回正确目录，不要为继续操作信任所有上级目录。公司电脑不允许安装时请联系 IT 支持人员。

</details>

步骤编号：E-02

## 第 3 步：准备两个安装包

**在哪操作**：浏览器 → Windows 文件夹

**这样做**：

1. 点击下方一个下载入口，下载两个文件：wsl.3.0.1.0.x64.msi 和 Docker Desktop Installer.exe。已有文件不用再下载。
2. 在课程资料文件夹旁新建 release 文件夹，把这两个文件放进去，先不用运行。
3. 下载不了也不用停在这里：下一步告诉 Trae“安装包还没下载，请帮我下载”。

[公司内下载](https://clouddrive.huawei.com/p/2c5dce71d71908a8c0c64574ee5ba886)


[公司外下载（提取码 egiy）](https://pan.baidu.com/s/1so3HddPOXQVl790421DczQ?pwd=egiy)


**完成后**：

- release 文件夹内有两个安装包。

**你来确认**：

- 两个文件已放好，或已准备在下一步请 Trae 代下载。

<details><summary>遇到问题再看</summary>

这两个文件用于准备课程工具。文件是否完整、版本是否合适，由 Trae 检查。

</details>

步骤编号：E-03

## 第 4 步：让 Trae 准备工具

**在哪操作**：Trae

**这样做**：

1. 在 Trae 点“打开文件夹”，选择解压后的课程资料文件夹。出现信任提示时，由本人核对并决定。
2. 在聊天框粘贴下方提示并发送；需要选择模式时，选 Agent（智能体）。
3. 按助手提示处理安装、条款或重启。重启后回到同一任务说“请继续准备工具”；等助手告诉你结果。

**现在复制到 Trae**：

```text
我要开始 AI Coding 课程。请读取当前文件夹的 setup-guide.md，安装课程助手并准备好工具；已有安装包直接用，缺少的请帮我下载。技术检查由你完成。需要我操作时，只告诉我在哪个窗口做什么；完成后用一句话告诉我结果。现在先不创建作品。
```


**完成后**：

- 助手告诉你工具是否准备好；未完成时给出下一步动作。

<details><summary>助手负责检查（你不用操作）</summary>

- 检查课程助手可用、工具安装与实际运行结果；缺项继续处理。
- 保存检查报告，用“已准备好”或“还没完成：缺什么”说明结果。

</details>

<details><summary>遇到问题再看</summary>

安装受限时把屏幕提示告诉助手；公司电脑确需 IT 处理时再联系 IT。你不用打开技能文件或判断安装日志。

</details>

步骤编号：E-04

## 第 5 步：课前接好云服务

**在哪操作**：Trae 与它打开的授权页面

**这样做**：

1. 在当前 Trae 任务发送下方提示。
2. 跟随助手打开的页面，本人完成登录或注册、实名和授权；已有账号直接用。
3. 查看助手说明的免费资格或费用，由本人决定；等它确认准备结果。

**现在复制到 Trae**：

```text
请用课程的云服务陪练带我准备腾讯云 CloudBase。已有账号和准备结果直接用；需要我登录、实名、授权或决定费用时，一次告诉我一个动作。配置和连接检查由你完成，最后告诉我是否准备好。
```


**完成后**：

- 助手确认云服务已准备好；未通过时说明当前缺项。

<details><summary>助手负责检查（你不用操作）</summary>

- 核对当前管理授权、本人练习空间和实际可用的工具。
- 保存准备结果；缺项说明原因，不把页面登录当连接成功。

</details>

<details><summary>遇到问题再看</summary>

密码、验证码和实名信息只在本人页面填写。此时不用创建作品或发布网页。

</details>

步骤编号：E-06

## 第 6 步：课前准备 GitHub 账号

**在哪操作**：Trae 与它打开的 GitHub 页面

**这样做**：

1. 在当前 Trae 任务发送下方提示；已有 GitHub 账号就直接用。
2. 按助手打开的页面完成本人登录或注册、邮箱验证。
3. 等助手确认账号准备好，再继续下一步。

**现在复制到 Trae**：

```text
请用课程的 GitHub 陪练带我准备免费账号。已有账号直接用；需要我操作时，一次告诉我一个动作。登录和邮箱状态由你检查，最后告诉我是否准备好。
```


**完成后**：

- 助手确认 GitHub 账号可以使用。

<details><summary>助手负责检查（你不用操作）</summary>

- 实际确认登录及邮箱验证状态，保存准备记录。

</details>

<details><summary>遇到问题再看</summary>

密码、验证码和条款由本人在官网处理，不发到聊天里。此时不用创建仓库或设置推送工具。

</details>

步骤编号：E-07

## 第 7 步：课前准备 AI 服务

**在哪操作**：Trae 与它打开的硅基流动页面

**这样做**：

1. 在当前 Trae 任务发送下方提示，已有硅基流动账号直接用。
2. 跟随页面登录，查看额度与费用，由本人决定是否继续。
3. 按助手指引创建或复用 Key（AI 服务的调用钥匙），只粘贴到它打开的隐藏输入窗口。等助手检查结果。

**现在复制到 Trae**：

```text
请用课程的硅基流动陪练带我准备 AI 服务。已有账号和 Key 直接用；先让我看清额度和费用，再带我安全保存 Key。地址配置和实际调用检查由你完成，最后告诉我是否准备好。
```


**完成后**：

- 助手确认 AI 服务可用，或说明尚缺哪一项。

<details><summary>助手负责检查（你不用操作）</summary>

- 安全保存 Key，检查课程所需的文字和识图调用，分别记录通过与未验证项。

</details>

<details><summary>遇到问题再看</summary>

Key 不发到聊天里。登录、条款和付费决定由本人处理；调用地址、模型和技术配置交给助手。

</details>

步骤编号：E-08

## 第 8 步：最后确认课前准备结果

**在哪操作**：Trae → 检查报告

**这样做**：

1. 发送下方提示，让 Trae 汇总前面各项准备结果。
2. 若助手说“还没完成”，只处理它指出的当前缺项。
3. 助手确认课前准备完成后，点“进入 AI Coding 操作手册”。

**现在复制到 Trae**：

```text
请汇总前面工具、云服务、GitHub 和 AI 服务的准备结果，必要时实际复查。缺项请继续处理；需要我操作时一次告诉我一个动作。最后用一句话说明课前是否已准备好，未通过的不要写成完成。现在先不创建作品。
```


**完成后**：

- 助手确认四项课前准备完成，可以开始课堂操作。

<details><summary>助手负责检查（你不用操作）</summary>

- 复查工具报告与各项服务的实际准备记录；工具通过不代替账号或 AI 服务通过。
- 有必要项未通过或未验证时保持未完成，给出下一动作。

</details>

<details><summary>遇到问题再看</summary>

你不用阅读日志或逐项检查配置；看助手的明确结论即可。此时还没有错题本页面是正常的。

</details>

步骤编号：E-05

## 过关检查

助手明确确认工具、云服务、GitHub 和 AI 服务已准备好；本人步骤已处理，未完成项不能略过。
