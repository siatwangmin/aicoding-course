热身：Hello Huawei

🎯用一个最简单的小任务热身：生成"我在华为工作了多少天"的网页。

在任意具有 AI 编程能力的工具（Gemini Canvas、Trae、WorkBuddy、华为员工助手等）中输入：

我是一名华为员工，想知道自己在华为工作了多少天。请生成一个网页，输入是加入华为的年月日，输出是在华为工作的总天数。

你可以使用 Gemini Canvas、Trae、WorkBuddy、华为员工助手等任何具有 AI 编程能力的工具，完成这个作业。

  4. 调用项目初始化 skill，完成项目初始化。输入：

请使用 Skill: ai-coding-cloudbase，把当前应用从本地单机改造为多设备共享的云端版，部署到腾讯云 CloudBase。 前置（本人已确认）： - 已有腾讯云 CloudBase 环境（PostgreSQL + 静态托管），并已取得发布用 Publishable Key。 - 场景：家庭成员跨设备访问同一份数据；访问网址本身即保密边界，不需要登录认证。 - 验收策略：全程免浏览器交互验证，采用"构建指纹核验 + Node 脚本端到端数据闭环"验收。 第 1 步 确认环境与目标 - 记录 envId、PG 实例、静态托管域名、已有表/字段、额度。 - 隔离规则：公开连接值（envId + Publishable Key）可进前端；管理/部署密钥严禁注入前端代码、Git 或编译产物。 第 2 步 数据库改为「环境内共享」（动数据库，不是只改前端） - 保留 RLS 为启用状态。 - 用一条 permissive 策略替代所有按用户隔离的策略： 对目标表 FOR ALL TO anon, authenticated USING (true) WITH CHECK (true)。 - 授予 anon（及 authenticated）表级 SELECT, INSERT, UPDATE, DELETE 权限。 - 把默认值为 auth.uid() 等用户绑定字段改为固定值（如 'shared'），历史数据一并统一至该值。 - 记录实际执行的 SQL 与核验数据（策略条数、RLS 状态、现有行数）。 第 3 步 前端去登录 + 接云端数据层 - SDK 初始化完全去除 auth 模块，不调用 app.auth，直接实例化 app.rdb()。 - 彻底移除全部认证逻辑：登录页路由、会话状态、登录/登出监听、鉴权门控组件。 - 数据层采用 PostgREST 风格 CRUD：select('*').range(0, 999) / insert / update().eq('id', id) / delete().eq('id', id)。 - 建立稳定的命名双向映射（前端 camelCase ↔ 数据库 snake_case）。 - 保留本地单机模式作为离线/异常回退方案（门面模式 + 动态 import）。 第 4 步 编译构建与前端产物自检 - 沿用当前容器/项目绑定的原生工具链构建，不引入新依赖，产出 dist。 - 静态产物自检（无需启动服务器）： * 确认 dist/index.html 与 assets 正常生成。 * 源码静态检查：确保无任何硬编码管理密钥（SecretKey / MasterKey）。 * 编译检查：`tsc --noEmit` 0 报错通过。 第 5 步 部署与静态发布核验（免浏览器） - 使用官方 CLI 发布至静态托管，记录 buildId 与访问 URL。 - 文件一致性校验：核对远程产物与本地 dist manifest 的 SHA-256 哈希值与文件清单。 - CDN 可达性抽检（仅发 1 条 HEAD/GET 请求）： * 仅校验静态根目录返回 HTTP 200/302，确认部署管道畅通。 * 忽略 CloudBase 默认域名的安全中间页或 Content-Disposition 标头，不运行无头浏览器爬取渲染。 第 6 步 跨设备共享契约验收（纯脚本闭环，替代浏览器多开测试） 编写一个独立的临时 Node.js 验收脚本，脱离浏览器直接测试 CloudBase 数据通路： 1. 客户端 A 写入：以匿名身份（Publishable Key）通过 SDK insert 一条带标记的测试记录 `__test_sync_probe__`。 2. 客户端 B 读取（模拟异地新设备）：使用独立上下文实例执行 select 查询，断言能成功读取该测试记录，证明环境内全员共享生效。 3. 客户端 A/B 清理：调用 delete 清理该测试记录，并再次验证 count 恢复。 4. 打印测试日志与退出状态（0 为全通），测试后自动移除该临时脚本。 5. 禁止浏览器自动化验收，真人试用由本人承担。 第 7 步 记录与交付 - 输出最终交付报告： * 环境参数与隔离模型（环境凭证即访问边界）。 * 数据库变更记录（RLS 策略快照、表权限）。 * 构建与发布证据（dist 哈希摘要、部署 buildId、访问 URL）。 * 脚本化跨设备共享测试的执行日志（写入、查验、清理全过程）。 * 提示用户：由于使用的是 CloudBase 默认域名，直接用外部浏览器初次打开时需跳过官方安全提示页，绑定自定义域名后可完全消除该中间页。
