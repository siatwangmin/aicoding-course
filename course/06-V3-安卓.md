# V3 安卓使用

更新手机设计，安装到安卓手机，检查与网页同步。

打开[操作网页](index.html)，按当前一步做。

**在哪操作**：Gemini

**这样做**：

1. 回原 Gemini 对话，提供 V2 完成情况；新对话上传最新两份设计文件。
2. 发送下面提示，确认手机的输入、查看与返回体验。

**复制发送**：

```text
云端网页已经能保存并共享错题。现在我要在安卓手机安装知错星，用同一练习账号，与网页共享题目、图片和掌握进度。请更新 PRD.md，考虑手机选图、手指画图、长题干、键盘弹出与返回操作，写出手机体验和双向同步的完成标准，保留已有功能。
```


[打开 Gemini](https://gemini.google.com/)


**完成后**：

- 包含手机场景的更新 PRD。

**检查**：

- 我知道手机上先试哪几个日常动作。

步骤编号：V3-01

步骤编号：V3-02

## 第 3 步：保存这一版的两份设计文件

**在哪操作**：Gemini → 浏览器 → Trae

**这样做**：

1. 沿用 D-05 的保存方法：原型有“下载”按钮就直接下载完整 HTML；没有时发送下方提示，取得两份原文。
2. 缺少文件时用“保存设计文件”粘贴并下载；打开 HTML 按本轮动作复试。
3. 复制下面的“保留旧版”提示到 Trae，等待实际备份完成，核对新旧材料路径。
4. 把本轮两份文件放到它报告的实际目录，回 Trae 说“新文件已放好，请读取并核对本轮变化”。

**复制发送**：

```text
这轮需求和原型我已确认。请在聊天中分别给出最新 PRD 的完整 Markdown 原文，以及已确认原型的完整单个 HTML 代码，方便我复制保存。保持设计不变；不要只给分享链接或只给部分代码。
```


[打开 Gemini](https://gemini.google.com/)

**文件下载后，先发给 Trae 保留旧版并打开目录**：

```text
请读取当前作品的实际需求与原型路径，先备份上一版并报告备份位置，再打开本轮材料的保存目录并给出完整路径。已有根目录材料沿用原位置，不迁移或初始化。我放入新文件后，请读取并核对本轮变化；记录新旧版本的真实路径与未验证项。
```


**完成后**：

- 本轮两份材料已被读取；上一版有实际备份路径，旧工程可沿用原文件名。

**检查**：

- 两份文件都换成了本轮确认版本，且 HTML 能打开试用。

## 第 5 步：装到手机，检查同步与操作

**在哪操作**：安卓手机与网页

**这样做**：

1. 用 USB 或你熟悉的文件传输方式，把 APK 传到安卓手机。
2. 在手机的文件管理中点 APK，按设备提示决定是否安装，打开知错星。
3. 打开后等待页面准备完成；手机新增题目和图片，网页刷新检查。
4. 网页修改或删除虚构题，手机刷新检查；试手绘、长题干、键盘和返回。

**复制发送**：

```text
我在安卓手机做了【动作】，期望【结果】，实际看到【现象】。请修复并给我新的安装文件和相同动作的复试步骤，保持网页功能与同步可用。
```


**完成后**：

- 手机可安装与使用，两端看到彼此的变化。

**检查**：

- 真机的选图、画图、输入与返回按设计可用。
- 手机与网页的题目、图片和进度双向共享。

<details><summary>遇到问题再看</summary>

手机不能用 localhost 访问电脑。使用助手确认可达的云端网址；已安装 APK 更新时保留同一应用身份和数据。若安装冲突先报告现象，不通过卸载清数据解决；系统安装和权限提示由本人判断。

</details>

步骤编号：V3-05
