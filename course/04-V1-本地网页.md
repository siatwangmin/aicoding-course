# V1 本地网页

让 Trae 实现网页，保存错题后刷新检查。

打开[操作网页](index.html)，按当前一步做。

## 第 1 步：让 Trae 按设计实现本地网页

**在哪操作**：Trae

**这样做**：

1. 确认上一阶段两份文件已放好并被读取。
2. 在同一个作品任务发送下面提示。
3. 跟随 Trae 先试录题与保存，再试复习卡片，最后试周末练习。

**复制发送**：

```text
第一版需求和 Canvas 原型已确认。请用知错星课程助手读取上一阶段核对过的真实需求和完整 HTML 路径，按原来的外观和操作继续当前本地网页。保留已有修改，不重新初始化、不迁移工程；已有功能先运行核对，再修复缺项。先检查录题与本机保存，再检查卡片复习和周末打印练习。每完成一个小成果，给我打开地址、试用动作与预期结果，并报告实际检查及未验证项。
```


**完成后**：

- 得到实际网页地址，出现按原型实现的错题本。

**检查**：

- Trae 给出的地址可以打开，并说明了先试哪个功能。

<details><summary>遇到问题再看</summary>

已有工程不要直接套用新模板路径。助手先核对当前作品的真实运行方式；旧的 Linux 依赖不能直接当作 Windows 依赖。电脑上已运行的工具箱可能挂载另一作品，必须核对挂载目录和网页端口，再沿用现有工具为当前作品启动页面；无需重新初始化。

</details>

步骤编号：V1-01

## 第 2 步：在浏览器检查保存和复习

**在哪操作**：浏览器

**这样做**：

1. 点击 Trae 返回的地址。录入“课堂样例：6×7”，选择数学、写一条错因、画一笔并保存。
2. 刷新，再关闭页面重新打开；检查题目、错因和图是否还在。
3. 翻卡、筛选学科，按已确认 Canvas 试等级变化；达到 LV3 后仍能在图鉴查看，周末练习不再选它。
4. 打开周末练习和打印预览；再用一条可删除的虚构题试修改、删除。

**复制发送**：

```text
我在本地网页做了【动作】，期望【结果】，实际看到【现象】。请对照已确认的需求和原型修复，并给我相同动作的复试步骤。
```


**完成后**：

- 记录真实保留；复习、掌握与周末练习按确认规则工作。

**检查**：

- 保存并刷新后题目与图片仍在。
- 掌握规则、页面外观和打印练习符合原型。

<details><summary>遇到问题再看</summary>

本机记录属于当前浏览器；换设备不会自动出现。清理浏览器数据会影响记录。

</details>

步骤编号：V1-02

## 第 3 步：记录结果，准备云端迭代

**在哪操作**：Trae

**这样做**：

2. 保留 Trae 给出的简短完成总结，下轮在 Gemini 说明已完成情况。

**复制发送**：

```text
请记录 V1 的实际检查结果和我的试用反馈，保留当前需求、原型与成果。告诉我已经能做什么、哪些还没验证；给我一段可以带回 Gemini 的完成总结。未通过的不要写成完成。
```


**完成后**：

- V1 完成记录和简短总结。

**检查**：

- 我知道已完成与未验证项，能讲清第一版的能力。

步骤编号：V1-03
