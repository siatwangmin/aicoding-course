# AI Coding 实操课

课前打开[环境准备](course/preparation.html)，上课打开[操作手册](course/index.html)，其他业务打开[自己的作品](course/custom.html)。资料由助手取得，手册、图片与求助在线阅读。

准备目录只处理工具与必要GitHub、CloudBase准备，不要求模型供应商账号。新环境采用Podman CLI和独立Compose；旧工程保持原绑定。

用户级统一提供 ai-coding-project/github/cloudbase/android；准备目录仅保留本地 env。任意作品初始化时原样复制标准 app，不询问平台选择，也不复制平台技能；后续按当前需求调用用户级技能。助手按项目AGENTS、开发工作流、Spec与进度直接开发；平台发布和安卓交付由对应用户级技能承担。

AI仅在当前功能需要时配置，Key在程序受保护设置中填写、由服务端保管。准备、接入、实际调用、发布、安装和本人试用分别验证。
