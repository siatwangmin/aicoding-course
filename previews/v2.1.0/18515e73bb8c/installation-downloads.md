# 在 Trae 准备课程资料

新课前准备统一使用 **Podman CLI + 独立 Docker Compose**，由 Trae 下载、配置和实际验证。无需 Docker Desktop 或 Podman Desktop，也无需为编排安装 Python。已有作品沿用原 runtime、connection 和镜像；助手保留数据并处理必要迁移，学员不执行命令。


1. 按课前网页从官网安装并打开 Trae，已有安装直接用。
2. 在 Trae 打开一个课程练习文件夹，复制课前第二步的提示。
3. Trae 连续完成资料下载、安装和工具检查；不用自己下载、解压或移动文件，也不用再发送一条准备提示。
4. 按提示处理本人条款、授权或重启；重启后回到同一任务继续。

课程资料是 GitHub 中的小资料包 `aicoding-student-kit.zip`。Podman、独立 Docker Compose 和 WSL 分别从官方地址取得，已有安装包直接复用；不再使用 GitHub Release 的完整软件合集。

下载失败时把提示告诉 Trae，让它从已有记录继续。你只需处理它指出的当前一步。

## 2.0 工程接续

环境在 A 准备，作品在新的 B 初始化；ai-coding-project 自动从用户级索引发现准备，接入 GitHub/CloudBase/AI，准备 Android 并生成项目根 AGENTS、技术基线和接续记录。大型环境数据默认 D 盘；本地运行、Web 编译和 APK 构建使用准备阶段同一已验证课程镜像。API Key 使用用户级加密存储与项目引用，不逐项目复制。

通用技能名单以 course-contract.json（维护源 course-contract/skills.json）为准：七项通用，明确选择某教学案例时另加其案例技能。通用开发调用 ai-coding-development，Android 调用 ai-coding-android；明确选择案例才读取案例业务。本人只做必要授权/费用决定、需求设计与亲自试用。配置、实际服务、构建、安装与本人试用分别留证。
