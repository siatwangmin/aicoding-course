# 卸载课程环境

用户说“卸载课程环境”或“清理本次测试安装”时，先走本页，不重新执行课前安装路线。

## 正向步骤

1. 从用户级生命周期 catalog、明确 A 和已登记 B 定位本次安装。多个目标不能唯一确定时只问目标；不扫描 HOME/磁盘找秘密。新包已记录安装归属；旧包用明确 A 生成 recovered 清单，未知项不猜。
2. 默认 KeepWork，保护作品源码、设计、Spec、数据和签名。TestClean 只删除明确选中的测试项目；展示其全部内容删除范围。云端、账号、手机和系统组件保留，另行授权/处理。
3. 用 `scripts/Uninstall-Course.ps1 -Mode Plan -InstallationId <真实ID>` 生成计划。也可用 `-PreparationDirectory <明确A>` 接管旧记录。助手读 plan.md 和计划 JSON，解释删除、恢复、共享保留、未知归属和冲突项。Plan 不停止资源、不解密 Key、不安装修复环境。
   虚拟机默认保留；即使引擎为空，也不能证明没有本人手工存放的文件。只有本人明确允许删除该虚拟机全部数据，才传 `-RemoveMachineNames <本次明确名称>`。保留虚拟机时其管理 CLI 同时保留；选择删除仍需通过归属、连接、两个命名空间和实际占用核验。
4. 在已明确授权范围执行 `-Mode Apply -PlanPath <实际计划路径> -PlanSha256 <实际摘要>`。入口复制独立 runner 到用户级操作目录后启动新进程；不能先手删 Skill。助手不能另写临时删除命令绕过核验。
5. 读取 result.json/result.md。0 表示选定范围验证通过；2 为未解决，4 为本人动作/重启，5 为计划变化需重算，1 为无效入口/计划。保持原资源和恢复依赖，按具体原因接续。删除动作不承诺完整回滚，数据删除没有备份不可恢复。
6. 需要接续时使用结果中的独立 runner，`-Mode Resume -OperationId <实际ID>`；复验用 `-Mode Verify`。部分卸载后资源归属/引用改变，按原安装生成新计划，不编辑 catalog 来伪造证据。保留 B 标记 detached；恢复用户级环境入口和同一批准准备后 Connect-Project 并实际核验。

## 独立使用

学员包、通用工具包根目录含 `卸载课程环境.cmd`，双击可在无 AI/Trae 时选择安装、范围和项目，预览真实清单后执行。同一核心、同一规则；不再另写一份 CMD 删除实现。

## 失败恢复

- `RESOURCE_MODIFIED` / `MANAGED_BLOCK_MODIFIED`：保留用户修改，助手定点比较、保存差异并重算计划；不得全文件覆盖或加 force。
- `ownership-unverified`：来源报告只能证明存在，不能证明独占。补创建/归属证据或保留，结果保持未完成；旧默认 machine 不自动删除。
- `RESOURCE_STILL_IN_USE` / `TOOL_HAS_REMAINING_RESOURCES`：检查全部引用和实际占用，只处理本次授权资源。失败依赖未解决前保留工具。
- `ENGINE_QUERY_FAILED` / `ENGINE_CLI_CHANGED_OR_MISSING`：不可访问不等于不存在。恢复原管理入口或人工核实；卸载器不新建 machine、不拉镜像、不安装替代引擎。
- machine 检查两个命名空间失败、离线、仍有其他镜像/卷/网络：保留并记录；不直接删 VHD、不全局 prune、不注销所有 WSL。
- `LIFECYCLE_BUSY`：等待已登记安装/构建操作结束，再接续；不强杀共享任务。残留租约核进程身份，不能仅按超时移除。
- 计划变化：重新 Plan；不复用旧摘要、不篡改结果。需要重启时保存工作，由本人重启后用独立 runner 接续。

完成报告分清本地删除、共享/主动保留、未知/失败、Trae 新会话观察、云端与手机。保留原报告、操作记录和仍需恢复的备份，清理策略/路径写明；不能声称零文件残留、云端已停费或磁盘等量释放。

重新安装从当前稳定下载入口重新解析实际发布版本/候选状态与摘要，创建新安装 ID，恢复旧 B 时保持原批准镜像。卸载不自动安装下一版，也不把旧成功记录当新环境就绪。
